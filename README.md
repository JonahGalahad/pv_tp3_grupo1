## Descripcion del Proyecto
Sistema web desarrollado con React para gestionar proyectos educativos mediante tarjetas dinámicas. Permite agregar, visualizar, buscar y eliminar proyectos, consultar detalles extendidos y administrar recursos e integrantes asociados, aplicando componentes reutilizables, manejo de estado y renderizado dinámico.
